# Узбекистан 20-30.10.2026: путеводитель-приложение

Работает на Samsung Galaxy Z Fold 5 (Chrome) и iPhone (Safari).

## Публикация через GitHub Pages
1. На github.com создайте репозиторий Public с любым непонятным именем, например `uz-7k2m9x`.
2. Загрузите в корень все файлы из этой папки: `index.html`, `manifest.webmanifest`, `sw.js`, папку `icons`, файл `.nojekyll`.
3. Settings, Pages: Source = Deploy from a branch, Branch = main, папка / (root), Save.
4. Через 1-2 минуты сайт откроется по адресу `https://ВАШ_ЛОГИН.github.io/ИМЯ_РЕПО/`.

## Установка на телефон
- Samsung (Chrome): откройте адрес, меню (три точки), «Установить приложение» или «Добавить на главный экран».
- iPhone (обязательно Safari): откройте адрес, кнопка «Поделиться», «На экран Домой», «Добавить».

Один раз откройте приложение с Wi-Fi и пролистайте разделы: после этого оно работает без интернета. Подложка карты подгружается только при сети, просмотренные участки сохраняются.

## Билеты
Раздел «Документы», блок «Мои файлы», кнопка «Добавить файлы». Файлы хранятся только в памяти телефона. На iPhone добавляйте их из установленного на экран Домой приложения, а не из вкладки Safari: так iOS не удалит их через неделю неиспользования.

## Обновление
Заменить `index.html` в репозитории, в `sw.js` увеличить номер версии (`uz-guide-v3` на `v4`), открыть приложение дважды.

Файл `uzbekistan_guide_FULL_with_tickets.html` с билетами внутри в репозиторий НЕ загружать.
